# Binary Search

**Difficulty:** Easy

## LeetCode Link

https://leetcode.com/problems/binary-search/

## Approach

Use two pointers to represent the left and right boundaries of the sorted array. Check the middle element and eliminate half of the search space after each comparison.

## Complexity

**Time:** O(log n)  
**Space:** O(1)
