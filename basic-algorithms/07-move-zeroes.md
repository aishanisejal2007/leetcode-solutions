# Move Zeroes

**Difficulty:** Easy

## LeetCode Link

https://leetcode.com/problems/move-zeroes/

## Approach

Keep a position pointer for the next non-zero element. Traverse the array and swap each non-zero element into the correct position, leaving all zeroes at the end.

## Complexity

**Time:** O(n)  
**Space:** O(1)
