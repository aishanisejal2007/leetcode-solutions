# Longest Common Prefix

**Difficulty:** Easy

## LeetCode Link

https://leetcode.com/problems/longest-common-prefix/

## Approach

Compare the characters of the first string with the corresponding characters in the other strings. Stop when a mismatch is found and return the common characters collected so far.

## Complexity

**Time:** O(n × m)  
**Space:** O(1)
