# Reverse a String

**Difficulty:** Easy

## LeetCode Link

https://leetcode.com/problems/reverse-string/

## Approach

Use two pointers, one at the beginning and one at the end of the string. Swap the characters at these positions and move the pointers toward the center until the string is completely reversed.

## Complexity

**Time:** O(n)  
**Space:** O(1)
