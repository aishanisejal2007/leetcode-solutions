# Best Time to Buy and Sell Stock

**Difficulty:** Easy

## LeetCode Link

https://leetcode.com/problems/best-time-to-buy-and-sell-stock/

## Approach

Keep track of the minimum stock price seen so far. For each price, calculate the possible profit and update the maximum profit if it is greater.

## Complexity

**Time:** O(n)  
**Space:** O(1)

Tested locally with two test cases and the solution was accepted on LeetCode.
