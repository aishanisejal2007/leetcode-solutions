# Valid Parentheses

**Difficulty:** Easy

## LeetCode Link

https://leetcode.com/problems/valid-parentheses/

## Approach

Use a stack to store opening brackets. When a closing bracket is encountered, compare it with the most recent opening bracket and ensure they form a valid pair.

## Complexity

**Time:** O(n)  
**Space:** O(n)
